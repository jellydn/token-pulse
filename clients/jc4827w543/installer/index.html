Check your board

JC4827W543C · ESP32-S3 · NV3041A QSPI · GT911 · 480 × 272

Not ESP32-4827S043 RGB. Chip detection cannot identify your display or PCB. Check the board marking before you connect.

Connect and install

  1. Use a USB-C data cable. Close other serial monitors.
  2. Use desktop Chrome or Edge on HTTPS. iOS browsers do not support Web Serial.
  3. Select your serial device. The installer shows progress and errors.
  4. After flashing, open Logs & Console, then use Settings on the panel.

Before you flash

This page is release preparation. No physical-board validation is claimed. Install only a package with a completed hardware test record.

Erase clears saved Wi-Fi and API settings. Back up your configuration first. A generic build has no publisher CA and cannot fetch verified HTTPS data: use a local build with your CA until a trusted release supports your origin.
